😈 -PingOfDead- 💀🧠

Descripción General

-PingOfDead- es una herramienta de diagnóstico y evaluación de conectividad de red inspirada en la utilidad estándar Ping, pero diseñada para ofrecer un control más granular sobre la prueba de latencia y la robustez de las conexiones.

⚠️ Aviso Legal:
El uso indebido de esta herramienta contra terceros no es responsabilidad de @cobravisualcode.
-PingOfDead- está destinada exclusivamente a fines educativos y pruebas de seguridad en entornos autorizados.

✨ Características Principales

Fácil de usar: Solo ingresa una dirección IP o dominio para iniciar la evaluación.

Configuración personalizada: Ajusta parámetros como el timeout y el tamaño del paquete.

Ejecución rápida: Inicia la herramienta con un solo clic tras la descarga.

Soporte de protocolos: Compatible con IPv4 e IPv6.

🛠️ Instrucciones de Uso

Sistemas compatibles: Windows 11, 10 y versiones anteriores.

Descarga el archivo +PingOfDead+.

🔬 Detalles Técnicos (Protocolo ICMP)

La funcionalidad central de -PingOfDead- se basa en el Protocolo ICMP (Internet Control Message Protocol).

Propósito del Ping:
Envía mensajes Echo Request y espera Echo Reply para medir la latencia y la tasa de éxito, lo que refleja la calidad de la conexión.

Protocolo ICMP:
Pertenece a la capa de red y se utiliza para el control, diagnóstico y generación de mensajes de error en la comunicación.

⚙️ Opciones del Protocolo
Opción	Descripción
-4	Utiliza exclusivamente IPv4
-6	Utiliza exclusivamente IPv6

También soporta consultas de información de nodo IPv6, según lo especificado en RFC4620.
